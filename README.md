# Q-FIS — Quantitative Finance and Investment Society

**Engineering. Finance. Research. Systems.**

Q-FIS is a student-led technical society bringing together students interested in the intersection of computer science, data science, mathematics, engineering and quantitative finance.

We believe financial markets are not just places where capital is traded. They are complex computational systems involving algorithms, statistics, data infrastructure, optimisation, distributed systems and decision-making under uncertainty.

Our goal is to explore these problems by learning, researching and building real technical systems.

## What We Do

We focus on four interconnected areas:

### Quantitative Research
Exploring mathematical and computational approaches to financial markets.

- Quantitative modelling and alpha research
- Statistical arbitrage and time-series analysis
- Derivatives and options pricing
- Market microstructure and simulation

### Machine Learning
Applying machine learning to financial data and decision systems.

- Retrieval-Augmented Generation (RAG)
- Information retrieval and ranking
- Machine learning for financial applications
- Model evaluation and experimentation

### Core Computer Science & Systems Engineering
Building the infrastructure that powers reliable, efficient software.

- Linux systems programming
- C/C++ and performance engineering
- Operating systems and computer networks
- Backend infrastructure and concurrent systems
- Storage, search and retrieval engines

### Data Engineering
Building reliable data foundations for financial research and applications.

- Financial data collection and ETL
- Data processing and validation
- Indian financial datasets
- APIs and data infrastructure

## What We're Building

Our work is organised around practical, research-oriented projects.

| Project | Description |
|---|---|
| Financial Document Assistant | A RAG-based assistant for searching and understanding financial documents |
| Core Systems Infrastructure | Systems components, networking services, storage and retrieval infrastructure |
| Market Ecology Simulator | An agent-based market microstructure simulation environment |
| Quantitative Finance Labs | Interactive tools for option pricing, derivatives and financial modelling |
| India Financial Data Repository | Structured, accessible datasets for Indian financial research |
| Quantitative Tools | Portfolio, backtesting, risk and financial data tools |

Projects evolve as research and implementation progress. Visit individual repositories for their current status, documentation and contribution opportunities.

## Our Approach

We are a project- and research-oriented community.

- **Learn by building:** Concepts become meaningful when implemented and tested.
- **Understand the fundamentals:** Mathematics, algorithms and systems matter as much as the final application.
- **Research independently:** Explore papers, documentation and existing implementations.
- **Build collaboratively:** Work through issues, code reviews, experiments and technical discussions.
- **Document what we learn:** Make our work and knowledge accessible to others.

## Contributing

We welcome students interested in computer science, mathematics, data science, engineering and quantitative finance.

You do not need to have a finance background to contribute. Curiosity, consistency and a willingness to learn are what matter.

To get started:

1. Explore the repositories and identify a project that interests you.
2. Read its README and contribution guidelines.
3. Look through open issues or discuss a possible contribution with the maintainers.
4. Fork the repository or create a branch, make your changes and open a pull request.
5. Explain your implementation and include relevant tests or experimental evidence.

Please read the contribution guidelines before submitting work.
